# RentWise: Expense & Affordability Tracker<br><br>

RentWise is a fast, client-side web application engineered to solve the financial complexities of shared living spaces. Moving beyond basic rent division calculators, this tool models realistic living arrangements and tracks the entirety of household expenses, from rent to utilities and groceries.<br><br>

It provides immediate calculations for fair cost distribution and actively monitors financial health against recognized real estate affordability thresholds, ensuring no roommate unknowingly takes on an unsustainable financial burden.<br><br>

### Core Features<br>
* **Advanced Split Engine:** Divide bills fairly using three distinct mathematical methods: Equal Split, Income-Weighted proportions, and Custom Percentages.<br>
* **Mathematical Validation:** Includes a strict validation engine that ensures custom percentage splits equal exactly 100%, preventing miscalculations.<br>
* **Dual Affordability Tracking:** Real-time visual meters flag individual and household spending as safe, approaching limits, or dangerously exceeding limits.<br>
* **Zero-Database Sharing:** Bypasses complex backend requirements by compiling the current state into a text-based report that copies directly to the clipboard.<br>
* **Customizable UI:** Features cross-currency support, a native color picker, and a seamlessly animated dark mode toggle.<br><br>

### Technical Architecture<br>
This project was intentionally built without heavy external frameworks to ensure lightweight performance, instantaneous load times, and complete data privacy.<br><br>
* **Structure:** HTML5 for semantic and accessible layout design.<br>
* **Styling:** CSS3 utilizing custom variables for immediate, responsive theme swapping.<br>
* **Logic Engine:** Vanilla JavaScript manages the application state, dynamic DOM rendering, and real-time algorithmic processing.<br><br>
